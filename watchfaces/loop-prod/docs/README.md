# Historical installer assets

ABI 2 installers are generated by the official Canopus CLI under `dist/installer/<family>/`. Run `python3 scripts/build.py` from the repository root in WSL; see `docs/BUILD.md`.

These tracked asset folders remain for source/history purposes. Do not package old ignored `.bin` payloads here. New CMI2 installers require a matching current ABI 2 Supervisor.
